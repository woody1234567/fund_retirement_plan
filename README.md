# fund_retirement_plan — 基金月配息退休試算工具

純前端網頁工具(Vue 3 + Pinia + Vite),讓理專輸入客戶持有的基金,估算每月配息總額,並判斷是否足以支應退休生活所需,結果可下載為 Excel。所有資料只存在瀏覽器本機(localStorage),不會上傳到任何伺服器。

## 快速開始

```sh
npm install --legacy-peer-deps   # 或 pnpm install
npm run dev                      # 開啟終端機顯示的網址(預設 http://localhost:5173)
```

> 專案要求 Node.js 22.18 以上(或 24.12 以上)。

## 使用說明

### 1. 設定客戶與退休目標

| 欄位                 | 說明                                          |
| -------------------- | --------------------------------------------- |
| 客戶姓名             | 選填,會出現在 Excel 標題與檔名                |
| 退休後每月所需生活費 | 台幣、以今日幣值計算                          |
| 預估年通膨率 (%)     | 用來推算退休時實際所需生活費,不考慮通膨請填 0 |
| 距離退休年數         | 已退休請填 0                                  |

通膨調整後每月所需 = 每月生活費 × (1 + 通膨率)^退休年數

### 2. 輸入持有基金

按「＋ 新增基金」新增一列,每檔基金填寫:

| 欄位             | 說明                                                 |
| ---------------- | ---------------------------------------------------- |
| 基金代碼 / 名稱  | 僅供辨識,例如 `AGF9`                                 |
| 幣別             | 基金計價幣別(TWD、USD、CNY、EUR、JPY、AUD、ZAR、HKD) |
| 配息頻率         | 月配、季配、半年配、年配                             |
| 投資金額         | 客戶投入金額,以基金計價幣別計                        |
| 市價(淨值)       | 目前每單位淨值,以基金計價幣別計                      |
| 每單位配息(單次) | 每次配息的每單位金額                                 |

基金的淨值與配息資料可參考[玉山銀行基金資訊頁](https://wealth.esunbank.com/zh-tw/fund/fund-info?fundCode=AGF9)(將網址中 `fundCode` 換成其他基金代碼即可查詢)。

每列右側會自動計算:

- **持有單位** = 投資金額 ÷ 市價
- **平均月配息** = 持有單位 × 每單位配息 × 每年配息次數 ÷ 12(季配、半年配、年配會平均分攤到每個月)
- **月配息(台幣)** = 平均月配息 × 匯率
- **年化配息率** = 年配息 ÷ 投資金額

使用外幣基金時,下方會出現**匯率**欄位(1 外幣 = ? 台幣),預設值僅為示意,請依當日匯率調整。

### 3. 查看試算結果

「試算結果」區塊會顯示投資總額、預估每月/每年配息、整體年化配息率、通膨調整後每月所需,以及**配息覆蓋率**(月配息 ÷ 每月所需):

- 覆蓋率 ≥ 100%:綠色,顯示每月結餘。
- 覆蓋率 < 100%:橘色,顯示每月缺口,並以目前平均配息率估算達標約需再投入的金額。

### 4. 下載 Excel

按右上角「下載 Excel」,會產生 `基金配息試算_客戶姓名_日期.xlsx`,內含各基金明細、摘要數據與結論,方便提供給客戶或存檔。

### 其他

- 資料會自動儲存在瀏覽器,重新整理後仍會保留;按「清空」可移除所有基金資料。
- 更換瀏覽器或電腦時資料不會同步,請以 Excel 保存結果。

### 試算限制

- 假設配息金額長期維持不變,實際配息可能變動,甚至可能含本金。
- 未計入稅費、手續費與匯率波動。
- 結果僅供參考,實際配息以基金公司公告為準。
